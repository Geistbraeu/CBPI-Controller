прокет предназначен для визуализации данных из cbpi4 на 4-х OLED.

# Железо
- контроллер - Raspberry Pi 5
- OLED - подключены по I2C через мультиплексор TCA9548A 
- адрес OLED - у всех одинаковый 0x3C
- адрес мультиплексора - 0x70
- OLED подключены к выходам 0-3  мультиплексора

# Api CBPI4
- базовый URL - http://localhost:8000
- базовый для танков - http://localhost:8000/kettle/
- базовый для сенсеров - http://localhost:8000/sensor/

# Алгоритм работы
- прочитать информацию о танках.  танк MT - заторник,  танк HLT - танк горячей воды.
- из информации о танках получаем их TargetTemp  и выводим на OLED 0 для MT и OLED 2 для HLT
- так же из танков получаем id сенсеров.
- читаем сенсоры и отображаем значения на OLED 1 для MT и OLED 3 для HLT.  лучше читать все сразу и потом искать нужныу в ответе, а не каждый по id
- интервал обновления данных - 1 секунда.

# Структура
- Displays-main.py  - точка входа и основной цикл
- CBPIService.py - вся работа с API CBPI
- OLEDService.py - вся работа с OLED

# Примеры
- \samples\oled.py - переключение oled и вывод на них информации
- \samples\cbpi.py - пример получения значения температуры от сенсора
- \samples\json\sensors.json - ответ на запрос http://localhost:8000/sensor/
- \samples\json\kettle.json - ответ на запрос http://localhost:8000/sensor/
